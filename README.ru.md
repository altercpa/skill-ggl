## Что это

[GGL.farm](https://ggl.farm) — сервис фермы Google-аккаунтов: он хранит ваши аккаунты и прокси, ведёт очередь
задач и работает через **ваш собственный антидетект-браузер** (Vision, OctoBrowser или AdsPower) на вашем
сервере. API повторяет веб-интерфейс, так что фермой из сотен аккаунтов можно управлять из скрипта.

Это **скилл** для [Claude](https://claude.com), который обучает его этому API. Просто опишите задачу —
скрипт, интеграцию или массовую операцию — и Claude напишет запросы с правильными методами, параметрами и
обработкой ошибок, а не будет угадывать. Спросите, как устроена сама ферма — что такое поток, что значит
ошибка `902`, что делает форма починки — и Claude прочтёт FAQ, а не станет гадать и тут.

## Что умеет

| Область | Что можно делать |
|---|---|
| **Аккаунты** | список и поиск, карточка аккаунта, регистрация новых, подключение существующих по логину и паролю или по профилю браузера, правка, массовая починка и удаление, открытие профиля для собственной автоматизации на Playwright, Puppeteer или Selenium |
| **Прокси** | поиск по пулу, добавление одного прокси или списка в разных форматах строк, слоты, проверка здоровья, правка, удаление |
| **Задачи** | постановка входа или настройки 2FA, список очереди, перезапуск задачи, закончившейся проблемой или ошибкой, отмена |
| **Интеграция** | подключение антидетект-браузера, выбор и настройка SMS-сервиса, ключ CapMonster, журнал запросов к вашему браузеру, нагрузка потоков вашего тарифа |
| **Команды** | взгляд администратора команды на аккаунты всех участников: список, карточка, починка, удаление |
| **Как работает ферма** | FAQ для клиентов — добавление и регистрация, потоки и лимиты, рабочий цикл, 2FA, прокси, SMS, команды, выбор сервера, коды ошибок, форма починки |

## Установка

### Claude Code

Скачайте [`altercpa-ggl-api-skill.zip`](https://github.com/altercpa/skill-ggl/releases/latest/download/altercpa-ggl-api-skill.zip)
и распакуйте в папку скиллов:

```sh
unzip altercpa-ggl-api-skill.zip -d ~/.claude/skills/     # для всех проектов
unzip altercpa-ggl-api-skill.zip -d .claude/skills/       # только для этого проекта
```

В Windows распакуйте в `%USERPROFILE%\.claude\skills\`.

Предпочитаете git? Клонируйте прямо в папку скиллов — обновление сводится к `git pull`:

```sh
git clone https://github.com/altercpa/skill-ggl.git ~/.claude/skills/altercpa-ggl-api
```

### Claude.ai и Claude Desktop

В настройках Claude добавьте собственный скилл и загрузите тот же zip.

## Как пользоваться

Вызывать ничего не нужно — Claude подключает скилл сам, когда запрос касается GGL.farm или его API.
Например:

- *Напиши скрипт на Python, который загружает мой список прокси в GGL.farm, проверяет их и удаляет те, что в ошибке.*
- *Добавь аккаунты из этого файла в GGL.farm с тегом `batch7` и включи фарм.*
- *У каких моих аккаунтов ошибка 902 и как починить их все одним вызовом?*
- *Открой браузерный профиль аккаунта 501 через CDP в Playwright и сделай скриншот.*
- *Что значит ошибка 102 и что с ней делать?*

Все вызовы устроены одинаково; токен — это `<user id>-<API key>` со страницы профиля на [ggl.farm](https://ggl.farm):

```
https://ggl.farm/api/{app}/{func}.json?id={token}
```
